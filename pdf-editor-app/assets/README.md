# Assets

## Icono de la Aplicación

Para la aplicación se necesita un icono en formato PNG de 512x512 píxeles.

### Crear el icono PNG

Si tienes ImageMagick instalado, puedes convertir el SVG a PNG:

```bash
convert icon.svg -resize 512x512 icon.png
```

O puedes usar herramientas en línea como:
- https://cloudconvert.com/svg-to-png
- https://convertio.co/es/svg-png/

También puedes usar cualquier editor de imágenes para crear un icono personalizado de 512x512 píxeles y guardarlo como `icon.png` en este directorio.

### Nota

El archivo `icon.svg` proporcionado es un icono de ejemplo. Puedes reemplazarlo con tu propio diseño.
